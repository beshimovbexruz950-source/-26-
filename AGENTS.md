## GitHub Push Workflow ("git hubga push xavsiz qil")
Har safar foydalanuvchi "git hubga push xavsiz qil" yoki loyihani GitHub-ga push qilishni so'raganda:
1. GitHub Repository: https://github.com/beshimovbexruz950-source/-26-.git
2. Branch: main
3. Token saqlangan joy: ~/.git-credentials faylida xavfsiz saqlangan. Foydalanuvchidan qayta token so'ralmasin.
4. Push qilish uchun mavjud skript yoki GitHub Contents API orqali barcha yangilangan fayllar avtomatik main branchga yuklanadi.
